# Job-Scheduling-for-Warehouse-Operation-in-Phyton
This project implements job scheduling for warehouse operations using the Shortest Job First (SJF) non-preemptive algorithm.
It simulates assigning jobs (like packing, loading, etc.) based on their burst time, aiming to minimize the overall waiting and turnaround time.
